# Random Letters

A single-page web app for generating random letters with customizable settings. Optimized for mobile devices and installable as a Progressive Web App (PWA).

## Features

- Generate random letters with a single tap
- Settings page with:
  - **Sampling mode**: Choose between "with replacement" (letters can repeat) or "without replacement" (each letter appears once before resetting)
  - **Letter exclusion**: Tap letters to exclude them from generation
- Mobile-friendly design
- Dark mode support
- Offline-capable (settings saved locally)

## Usage

1. Open `index.html` in a web browser
2. Tap "Generate Letter" to get a random letter
3. Tap the settings icon to configure options
4. On mobile devices, you can add it to your home screen for quick access

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and responsive design
- `app.js` - Application logic
- `manifest.json` - PWA manifest for installability

## Browser Support

Works in all modern browsers. For PWA features (install to home screen), use Chrome, Edge, Safari, or Firefox on mobile devices.
